Neural Networks.

Explore the computational models behind many modern AI systems and learn how interconnected layers can transform inputs into useful predictions and outputs.

What Is a Neural Network?

A neural network is a mathematical model made from interconnected computational units, commonly called artificial neurons. Networks can learn useful patterns from data by adjusting their parameters during training.

The Basic Structure

📥

Input Layer

Receives the numerical representation of the information supplied to the network.

🧠

Hidden Layers

Transform information using learned weights, biases and activation functions.

📤

Output Layer

Produces the network's final output, such as a prediction, classification or probability.

Inside an Artificial Neuron

An artificial neuron combines input values with learned weights and a bias, then passes the result through an activation function.

⚙️ Neuron Calculation

A simplified neuron can be represented mathematically as:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

The value z is then passed through an activation function to produce the neuron's output.

Important Components

⚖️ Weights

Weights determine how strongly individual inputs influence a neuron's calculation.

➕ Bias

A bias is an additional learned parameter that allows the neuron's activation to shift.

〰️ Activation Function

Activation functions introduce nonlinear behavior, allowing networks to represent more complex relationships.

📐 Parameters

The weights and biases of a neural network are commonly referred to as its parameters.

Common Activation Functions

ReLU

A widely used activation function in neural networks.

ReLU(x) = max(0,x)

Sigmoid

Maps an input to a value between 0 and 1 and has historically been useful in several types of models.

Softmax

Converts a collection of values into a probability distribution whose values sum to 1.

How a Neural Network Learns

1

📥 Input

Training data is supplied to the network.

2

➡️ Forward Pass

The input moves through the layers and produces a prediction.

3

📉 Calculate Error

A loss function measures how different the model's prediction is from the desired training outcome.

4

↩️ Backpropagation

Gradients are calculated to determine how changes in the network's parameters would affect the loss.

5

🔧 Update Parameters

An optimization algorithm such as gradient descent adjusts parameters to reduce the training loss.

Types of Neural Networks

🔗

Feedforward Networks

Information generally moves from the input layer toward the output without feedback connections.

👁️

Convolutional Neural Networks

CNNs are especially useful for processing structured grid-like data such as images.

🔄

Recurrent Neural Networks

RNNs were designed to process sequences by maintaining information across steps.

⚡

Transformers

Transformer architectures use attention mechanisms to process relationships between elements in data sequences and are widely used in modern AI.

Where Neural Networks Are Used

👁️ Computer Vision

Image classification, object detection and other visual-processing tasks.

💬 Language

Language understanding, translation, summarization and text generation.

🎙️ Speech

Speech recognition and other audio-processing tasks.

🤖 Robotics

Neural networks can help robots perceive their surroundings and make predictions or control decisions.

Neural Networks vs. Human Brains

Artificial neural networks were partly inspired by ideas from neuroscience, but they are not literal copies of the human brain. Biological neurons and artificial neurons operate through very different physical mechanisms.

🧠 QENOAIX Fact

A neural network does not learn by simply memorizing every training example. During training, its parameters are adjusted so that the model can learn useful statistical relationships and generalize to new inputs.
