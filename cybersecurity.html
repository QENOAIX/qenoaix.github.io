Cybersecurity.

Explore the science and engineering behind protecting computers, networks, applications and digital information from unauthorized access, disruption and misuse.

What Is Cybersecurity?

Cybersecurity is the practice of protecting digital systems, networks, applications and information from threats while maintaining their confidentiality, integrity and availability.

Confidentiality

Ensuring that information is accessible only to authorized people and systems.

Integrity

Protecting information from unauthorized alteration or accidental modification.

Availability

Keeping systems and information accessible when authorized users need them.

How Cybersecurity Works

Security uses multiple layers of technologies and practices to identify risks, protect systems and respond to problems.

01

Identify

Organizations identify important systems, information, devices and potential security risks.

02

Protect

Security controls such as authentication, encryption and access management help reduce risks.

03

Detect

Monitoring systems can identify unusual activity and potential security events.

04

Respond

Security teams investigate incidents and take appropriate actions to contain them.

05

Recover

Systems can be restored and security practices improved after an incident.

Security Pipeline

A simplified model of the cybersecurity lifecycle.

IDENTIFY ↓ PROTECT ↓ DETECT ↓ RESPOND ↓ RECOVER ↓ IMPROVE

Core Areas of Cybersecurity

Cybersecurity covers many different areas because modern digital systems have many layers that need protection.

Network Security

Protecting networks and communications from unauthorized access and harmful activity.

Application Security

Designing and maintaining software with security protections throughout its development.

Cloud Security

Protecting applications, data and infrastructure hosted on cloud computing platforms.

Data Security

Protecting information throughout its storage, processing and transmission.

Identity & Access

Managing who can access systems and what resources they are allowed to use.

Security Operations

Monitoring systems, investigating alerts and coordinating responses to security events.

Authentication & Access

Authentication verifies identity, while authorization determines what an authenticated user or system is allowed to access.

Passwords

Secret credentials can be used to verify a user's identity when accessing an account.

Multi-Factor Authentication

Multiple independent verification factors can provide stronger protection than a password alone.

Authorization

Access-control systems determine which resources an authenticated identity can use.

Encryption

Encryption transforms readable information into a protected form so that only authorized parties with the appropriate key can recover the original information.

Symmetric Encryption

The same secret key is used for encryption and decryption.

Asymmetric Encryption

A pair of related keys can be used for encryption, decryption and secure communication.

Hashing

Hash functions produce fixed-size values that can help verify data and securely handle certain credentials.

Security Technologies

Firewalls

Security controls can filter network traffic according to defined rules.

Intrusion Detection

Monitoring systems can identify suspicious patterns and potential security events.

Endpoint Security

Computers and other connected devices can be protected through security software and management systems.

Security Monitoring

Logs and system events can be analyzed to detect unusual activity.

Backups

Reliable backups help organizations recover important information after failures or security incidents.

Secure Development

Security can be integrated throughout the software development lifecycle.

Cybersecurity & AI

Artificial intelligence can assist cybersecurity by analyzing large amounts of information, identifying unusual patterns and helping security teams prioritize events.

Anomaly Detection

Machine learning systems can help identify activity that differs from expected patterns.

Threat Analysis

AI systems can assist analysts in processing large quantities of security information.

Automated Defense

Some security systems can automatically respond to predefined or detected events.

Good Security Practices

Keep Software Updated

Updates can include important security fixes and improvements.

Use Strong Authentication

Strong authentication methods reduce the risk of unauthorized account access.

Protect Important Data

Sensitive information should be handled carefully and protected with appropriate security controls.

The Future of Cybersecurity

As connected devices, cloud computing and AI continue to grow, cybersecurity will become increasingly important across digital infrastructure.

AI-Assisted Security

Intelligent systems may help security teams analyze increasingly large and complex datasets.

Zero Trust

Modern security architectures can continuously verify identities, devices and access requests.

Secure Connected Systems

IoT devices, vehicles, infrastructure and other connected systems will require stronger security.
