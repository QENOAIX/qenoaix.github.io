Encryption.

Encryption transforms readable information into a scrambled form that only authorized parties can turn back into its original meaning, protecting data as it's stored and sent.

What Is Encryption?

Encryption is the process of converting readable data, called plaintext, into an unreadable form, called ciphertext, using a mathematical algorithm and a key.

Only someone with the correct key can reverse the process and turn the ciphertext back into usable plaintext, a process known as decryption.

💡 Simple Idea

Think of encryption like locking a message in a box. Anyone can see the box, but only someone with the right key can open it and read what's inside.

Core Concepts

01 — PLAINTEXT

Plaintext

The original, readable data before it has been encrypted.

02 — CIPHERTEXT

Ciphertext

The scrambled, unreadable result produced after encryption is applied.

03 — KEY

Key

A piece of information used by the algorithm to encrypt or decrypt data.

04 — CIPHER

Cipher

The algorithm that defines the steps used to perform encryption and decryption.

Types of Encryption

🔑

Symmetric Encryption

Uses the same key to both encrypt and decrypt data. It is fast and efficient for large amounts of data.

🔐

Asymmetric Encryption

Uses a pair of keys — a public key to encrypt and a private key to decrypt — removing the need to share a single secret key.

How Asymmetric Encryption Works

1

🗝️ Key Pair Generation

A public key and a private key are generated together and mathematically linked.

2

📤 Share the Public Key

The public key can be shared openly with anyone who wants to send encrypted data.

3

🔒 Encrypt the Message

The sender uses the recipient's public key to encrypt the message into ciphertext.

4

📥 Send Ciphertext

The encrypted message is transmitted, even over insecure channels, since it can't be read without the private key.

5

🔓 Decrypt with Private Key

Only the recipient, holding the matching private key, can decrypt the message back into plaintext.

Common Encryption Algorithms

Algorithm Type Common Use
AES Symmetric Encrypting files, disks and secure connections.
DES / 3DES Symmetric Older standard, largely replaced by AES.
RSA Asymmetric Secure key exchange and digital signatures.
ECC Asymmetric Strong security with smaller key sizes.
SHA-256 Hashing Verifying data integrity and password storage.

Encryption vs. Hashing

Encryption and hashing are both used to protect data, but they serve different purposes.

🔁 Encryption

A reversible process — data can be decrypted back into its original form using the correct key.

🧮 Hashing

A one-way process — the original data cannot be recovered from the hash, which is why it's used to verify data or store passwords.

Where Encryption Is Used

  • Securing websites through HTTPS connections.
  • Protecting messages in end-to-end encrypted chat apps.
  • Encrypting files and folders stored on a device or in the cloud.
  • Securing online banking and payment transactions.
  • Protecting Wi-Fi networks from unauthorized access.
  • Verifying software updates haven't been tampered with.
  • Signing and verifying digital documents.

Encryption and Security

✅ Confidentiality

Ensures that only authorized parties can read the protected information.

✅ Integrity

Helps confirm that data has not been altered during storage or transmission.

⚠️ Key Management

Encryption is only as strong as how well its keys are generated, stored and protected.

⚠️ Performance

Stronger encryption can require more computing resources, which may affect speed.

Did You Know?

🧠 QENOAIX Fact

Encryption isn't new — early forms date back thousands of years, including the Caesar cipher used by Julius Caesar to protect military messages by shifting each letter in the alphabet.

One-Sentence Takeaway

Encryption turns readable information into a locked form that only the right key can open, keeping data private as it moves and rests.
