AI / COMPUTER SCIENCE

Algorithms.
Ideas in motion.

Algorithms are step-by-step procedures used to solve problems, process information, search through data, make decisions and build intelligent systems.

01 / FOUNDATION

What is an Algorithm?

An algorithm is a finite sequence of clear and ordered instructions designed to solve a problem or perform a particular task.

Computers use algorithms to process data, perform calculations, search information, organize data and make decisions.

Simple idea: An algorithm is like a recipe for solving a problem. It tells us what steps to perform and in what order.
02 / STRUCTURE

Properties of an Algorithm

01 — INPUT

Input

An algorithm can receive one or more values that it needs to process.

02 — OUTPUT

Output

It should produce a meaningful result after processing the input.

03 — DEFINITENESS

Clear Steps

Every instruction should be precise and unambiguous.

04 — FINITENESS

Termination

A proper algorithm should eventually finish after a finite number of steps.

03 / EXAMPLE

Finding the Largest Number

Imagine we have a list of numbers and want to find the largest one.

  1. Take the first number as the current largest.
  2. Compare it with the next number.
  3. If the next number is larger, make it the new largest.
  4. Continue until every number has been checked.
  5. The current largest number is the answer.
04 / SEARCHING

Searching Algorithms

SEARCH / 01

Linear Search

Linear search checks elements one by one until the required element is found or the entire collection has been checked.

Time Complexity: O(n)
SEARCH / 02

Binary Search

Binary search works on sorted data and repeatedly divides the search space into two parts.

Time Complexity: O(log n)
05 / SORTING

Sorting Algorithms

Sorting algorithms arrange data into a particular order, such as ascending or descending order.

Algorithm Basic Idea Typical Complexity
Bubble Sort Compare and swap adjacent elements. O(n²)
Selection Sort Select the smallest remaining element. O(n²)
Insertion Sort Insert elements into their correct position. O(n²)
Merge Sort Divide data and merge sorted portions. O(n log n)
Quick Sort Partition data around a pivot. O(n log n) average
06 / GRAPH ALGORITHMS

Algorithms for Networks

Graphs represent relationships between objects using vertices and edges. Graph algorithms are important in networks, navigation, social platforms and computer science.

GRAPH / 01

Breadth-First Search

BFS explores a graph level by level from a starting vertex.

GRAPH / 02

Depth-First Search

DFS explores deeply along a path before backtracking.

GRAPH / 03

Dijkstra's Algorithm

Dijkstra's algorithm finds shortest paths from a source vertex when edge weights are non-negative.

GRAPH / 04

Minimum Spanning Tree

Kruskal's and Prim's algorithms can construct minimum spanning trees.

07 / PERFORMANCE

Algorithm Complexity

Algorithm complexity describes how the resources required by an algorithm change as the size of the input increases.

Time Complexity

Time complexity describes how the number of computational operations grows as the input becomes larger.

Space Complexity

Space complexity describes how much additional memory an algorithm requires.

O(1) → O(log n) → O(n) → O(n log n) → O(n²)

10 / CONCEPT

Algorithm vs Program

An algorithm is the logical procedure used to solve a problem, while a program is an implementation of that procedure using a programming language.

Think of it this way: The algorithm is the plan. The program is the coded execution of that plan.
11 / HISTORY

Where Did the Word Come From?

The word "algorithm" is derived from the name of the Persian mathematician Muhammad ibn Musa al-Khwarizmi.

His mathematical works played an important role in the development of mathematics and computational thinking.

12 / TAKEAWAY

The Big Idea

Algorithms turn problems into precise computational processes. They provide the logical foundation behind software, computer science, machine learning, artificial intelligence and many technologies we use every day.
