01 — What are Algorithms?

Turning problems into logical steps.

An algorithm is a finite sequence of clear instructions designed to solve a problem or complete a task. Algorithms are everywhere in computer science — from searching for a website to organizing millions of pieces of data.

03 — Algorithm Complexity

How efficient

An algorithm may solve a problem correctly but still be inefficient. Complexity analysis helps us understand how the time and memory requirements of an algorithm change as the input becomes larger.

O(1) Constant Time
O(log n) Logarithmic Time
O(n) Linear Time

O(n²) Quadratic Time
O(2ⁿ) Exponential Time
