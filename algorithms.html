Algorithms.
Ideas in motion.

Algorithms are step-by-step procedures used to solve problems, process information, make decisions and transform inputs into useful outputs.

What is an Algorithm?

An algorithm is a finite sequence of clear instructions designed to solve a particular problem or perform a specific task.

Algorithms are everywhere. Searching for a website, sorting a list, finding the shortest route on a map and training an AI system all involve algorithms.

Simple idea: An algorithm is like a recipe for solving a problem — it tells a computer what steps to perform and in what order.

Properties of a Good Algorithm

01 — INPUT

Input

An algorithm may receive one or more inputs that it needs to process.

02 — OUTPUT

Output

It should produce a useful result after processing the input.

03 — DEFINITENESS

Clear Steps

Every instruction should be precise and unambiguous.

04 — FINITENESS

Termination

A proper algorithm should eventually stop after a finite number of steps.

Example: Finding the Largest Number

Suppose we have a list of numbers and want to find the largest one.

  1. Take the first number as the current largest.
  2. Compare it with the next number.
  3. If the next number is larger, make it the new largest.
  4. Continue until every number has been checked.
  5. The remaining largest value is the answer.

Algorithms in Computer Science

SORTING

Sorting Algorithms

Arrange data into a particular order, such as ascending or descending order.

Examples include Bubble Sort, Selection Sort, Insertion Sort, Merge Sort and Quick Sort.

SEARCHING

Searching Algorithms

Find a particular item inside a collection of data.

Examples include Linear Search and Binary Search.

GRAPH

Graph Algorithms

Work with networks of connected objects called vertices and edges.

Examples include BFS, DFS and Dijkstra's algorithm.

OPTIMIZATION

Optimization Algorithms

Try to find the best solution according to a particular objective or constraint.

Searching Algorithms

Linear Search

Linear search checks elements one by one until the desired element is found.

Time Complexity: O(n)

Binary Search

Binary search works on sorted data. It repeatedly divides the search space into two parts.

Time Complexity: O(log n)

Sorting Algorithms

Algorithm Basic Idea Typical Time Complexity
Bubble Sort Repeatedly swap adjacent elements. O(n²)
Selection Sort Select the smallest remaining element. O(n²)
Insertion Sort Insert each element into its correct position. O(n²)
Merge Sort Divide the list and merge sorted parts. O(n log n)
Quick Sort Partition data around a pivot. O(n log n) average

What is Algorithm Complexity?

Algorithm complexity describes how the resources required by an algorithm change as the amount of input data increases.

Time Complexity

Time complexity describes how the number of computational steps grows with the size of the input.

Space Complexity

Space complexity describes how much additional memory an algorithm requires as the input size grows.

Common notation: O(1), O(log n), O(n), O(n log n), O(n²)

Artificial intelligence depends heavily on algorithms. AI systems use algorithms to learn patterns, process information, search through possible solutions and make predictions.

MACHINE LEARNING

Learning Algorithms

Algorithms such as linear regression, decision trees and gradient-based methods can learn patterns from data.

SEARCH

Search Algorithms

OPTIMIZATION

Optimization

ROBOTICS

Decision Making

Robots use algorithms for navigation, perception, planning and control.

Algorithms in Everyday Life

  • Search engines rank and retrieve information.
  • Maps calculate routes between locations.
  • Streaming services recommend content.
  • Online stores recommend products.
  • Image-processing systems detect objects.
  • Financial systems process transactions.
  • Games use algorithms for computer-controlled characters.

Algorithm vs Program

An algorithm is the logical procedure for solving a problem, while a program is an implementation of that procedure in a programming language.

Think of it this way: The algorithm is the plan; the program is the coded execution of that plan.

Did You Know?

The word "algorithm" is derived from the name of the Persian mathematician Muhammad ibn Musa al-Khwarizmi, whose works played an important role in the development of mathematics and computation.

One-Sentence Takeaway

Algorithms are precise step-by-step methods that turn problems into solvable computational processes.
