DATA — MACHINE LEARNING

Data is the foundation of Machine Learning.

Machine Learning systems learn patterns from data. The quality, quantity and preparation of that data can strongly influence how well a model performs.

01 — COLLECTION

Data Collection

Data can be collected from databases, sensors, applications, experiments, websites, APIs and many other sources.

02 — TYPES

Types of Data

Machine Learning can work with numerical data, categorical data, text, images, audio, video and time-series data.

03 — PREPARATION

Data Preprocessing

Raw data often needs to be cleaned and transformed. Missing values, duplicate records and inconsistent formats can be handled before training.

04 — FEATURES

Features & Labels

Features are input variables used by a model. A label is the target output that the model is trained to predict in supervised learning.

05 — TRAINING

Training Data

Training data is used by a Machine Learning algorithm to learn relationships and patterns from examples.

06 — TESTING

Test Data

Test data contains examples that the model has not used during training. It helps evaluate how well the model generalizes to unseen data.

Key Idea

A Machine Learning model is only as useful as the data and process used to train and evaluate it. Good data helps models learn meaningful patterns and make more reliable predictions.
